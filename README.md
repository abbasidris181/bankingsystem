# GPT Bank - Banking Management System

A full-stack banking management application built as part of my PHP Mastery journey.

## Features

- Admin authentication
- Role authorization
- Customer CRUD
- Savings accounts
- Current accounts
- Deposits
- Withdrawals
- Account transfers
- Transaction history
- Dashboard statistics
- Chart.js reports
- CSRF protection
- SweetAlert2 confirmations
- iziToast notifications

## Technologies

- PHP 8+
- Object-Oriented PHP
- MySQL
- PDO
- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- Chart.js
- SweetAlert2
- iziToast
- Git

## Architecture

The project uses a beginner-friendly layered structure:

- Models
- Repositories
- Services
- Pages
- Shared includes

## Learning Purpose

This project demonstrates core PHP OOP concepts before transitioning into PDO, MVC and Laravel.
